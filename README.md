# Сплит

Коллажи для Instagram (сторис 1080×1920, пост 1080×1350) прямо в браузере. Фото не покидают устройство: всё считается локально, сервер только отдаёт статические файлы.

## Публикация на GitHub Pages

Публикация запускается только вручную, пуш в `main` сам по себе сайт не меняет.

1. Один раз: Settings → Pages → Source: **GitHub Actions**.
2. Actions → «Публикация на GitHub Pages» → **Run workflow**.
3. Через минуту приложение будет по адресу https://bukthorn.github.io/split/.

Сборки нет: на сайт копируются файлы приложения как есть (список в `.github/workflows/pages.yml`).

## Установка на iPhone

Открыть ссылку в Safari → «Поделиться» → «На экран Домой». После первого запуска работает без интернета.

## Локальный запуск

```
python -m http.server 8000
```

и открыть http://localhost:8000. На телефоне по локальной сети не заработают service worker и «Поделиться»: им нужен HTTPS, поэтому проверять на айфоне удобнее через GitHub Pages.

## Обновления

Service worker отдаёт приложение из кэша и в фоне подтягивает новую версию, так что она появляется со следующего запуска. Если поменялся список файлов, нужно обновить `ASSETS` и поднять версию `CACHE` в `sw.js`.
